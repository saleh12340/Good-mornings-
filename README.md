# تطبيق بقالة ومركز العزيزي (Alizzi Grocery)

تطبيق متكامل لإدارة المبيعات، الحسابات، الديون، الفواتير، والمخزون للمحلات التجارية والبقالات، مبني بأحدث تقنيات أندرويد (Kotlin + Jetpack Compose + Material 3).

---

## 🚀 سير العمل في GitHub (GitHub Actions CI/CD)

يحتوي المستودع على ملف سير عمل جاهز ومؤتمت بالكامل في المسار:
`.github/workflows/android.yml`

### ما يقوم به سير العمل تلقائياً:
1. **التحقق من الكود (Checkout):** جلب كود المشروع عند كل `push` أو `pull request` لفرعي `main` و `master`.
2. **إعداد بيئة العمل (Setup Environment):** تجهيز Java JDK 21 و Gradle 9.3 مع نظام كاش سريع للمكتبات.
3. **استرجاع مفتاح التوقيع (Keystore):** فك ترميز `debug.keystore.base64` تلقائياً لضمان بناء حزمة APK بدون أي أخطاء متعلقة بملف التوقيع.
4. **تشغيل الاختبارات (Run Tests):** تشغيل كافة اختبارات الوحدة واختبارات Robolectric والتأكد من سلامة النظام.
5. **بناء وتوليد حزمة APK (Assemble Debug APK):** تجميع التطبيق بنسخة APK جاهزة للتثبيت على الهواتف.
6. **رفع الحزمة (Upload Artifacts):** حفظ ملف الـ APK في قسم **Actions > Artifacts** داخل مستودع GitHub لتتمكن من تنزيله وتثبيته مباشرة على الهاتف.

---

## 🛠️ كيفية تفعيل واستخدام سير العمل في GitHub:
1. ارفع المشروع إلى مستودعك على GitHub.
2. ادخل إلى تبويب **Actions** في صفحة المستودع.
3. ستجد سير العمل باسم **Android CI & Build APK**.
4. سيعمل تلقائياً مع كل تحديث ترسله للكود، أو يمكنك تشغيله يدوياً بالضغط على **Run workflow**.
5. بمجرد انتهاء البناء بنجاح (علامة صح خضراء ✅)، انزل لأسفل الصفحة في قسم **Artifacts** وحمّل ملف:
   `AlizziGrocery-Debug-APK.zip`
   وفك ضغطه لتحصل على ملف الـ APK وتثبته على هاتفك فوراً.

## 📱 التقنيات المستخدمة:
- **لغة البرمجة:** Kotlin 2.2
- **واجهة المستخدم:** Jetpack Compose + Material 3
- **قاعدة البيانات:** Room Database (Offline-first & Persistent)
- **الطباعة والتصدير:** إنشاء وتصدير الفواتير PDF ومشاركتها عبر واتساب
