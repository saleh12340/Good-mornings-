# بقالة العزي للمواد الغذائية — مشروع Android

مشروع Android أصلي بلغة Kotlin وواجهة Jetpack Compose. أُنشئت الملفات الناقصة واستُبدلت الشاشة التجريبية بنواة عملية قابلة للتطوير.

## الوظائف المنفذة في المصدر
- شاشة رئيسية تعرض العملاء وإجمالي أرصدتهم.
- إضافة عميل مع الاسم والهاتف والملاحظات.
- صفحة مستقلة لكل عميل.
- إضافة فاتورة أو عملية دين أو سند قبض، مع تعديل العملية وحذفها.
- حساب الرصيد تلقائيًا: الفواتير/الديون تزيد الرصيد، والقبض يخفضه.
- حفظ البيانات محليًا باستخدام SharedPreferences بصيغة JSON، وتبقى بعد إغلاق التطبيق.
- مشاركة كشف حساب أو إيصال عبر تطبيقات الهاتف.
- اختيار جهاز Bluetooth مقترن ومحاولة إرسال الإيصال بأوامر ESC/POS.
- واجهة عربية RTL مصممة للهاتف، بترويسة وبطاقات مضغوطة نسبيًا.

## البناء
1. افتح المجلد في Android Studio حديث يدعم Android Gradle Plugin 8.7.3 وKotlin 2.0.21.
2. اسمح بمزامنة Gradle وتنزيل الاعتماديات.
3. شغّل التطبيق على جهاز Android 8.0 أو أحدث.

## ملاحظات صريحة قبل الاستخدام التجاري
- هذا مشروع مُعاد بناؤه، وليس استعادة للكود أو قاعدة البيانات الخاصة بملف APK القديم.
- البيانات محفوظة محليًا على الجهاز فقط؛ لا يوجد نسخ احتياطي سحابي أو مزامنة بين الأجهزة.
- الطباعة تحاول إرسال نص UTF-8 عبر Bluetooth Classic SPP. بعض طابعات 58 مم لا تعرض العربية مباشرة وتحتاج إلى تحويل النص إلى صورة/أوامر ESC/POS خاصة بموديل الطابعة. يجب اختبارها على الطابعة الفعلية قبل الاعتماد عليها.
- لم يُرفق APK مبني أو موقّع؛ يلزم بناء المشروع واختباره من Android Studio. لا أزعم نجاح البناء قبل تشغيله فعليًا.
- الخطوط تعتمد حاليًا على خط النظام. يمكن إضافة ملف Amiri TTF مرخّص إلى `app/src/main/res/font/` وربطه بواجهة Compose في مرحلة لاحقة.
- لم تتم إضافة أصناف مخزون أو ميزات ضريبية أو مزامنة؛ حقل تفاصيل الفاتورة متاح لتسجيل الأصناف كنص في هذه النسخة.
